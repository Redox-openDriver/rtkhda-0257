# Безопасность

## Что делает демон на Redox
`rtkhdad` получает контроллер HD Audio (AMD 1022:15e3) от `pcid`: регистры BAR0, прерывание и память для DMA.
Кодеку он отправляет только команды, которые строит библиотека [sonus](https://github.com/Redox-openDriver/sonus):
выбор выходов и входов, усиление, громкость. Служебных команд Realtek, которые меняют прошивку или память кодека,
драйвер не строит; наушники включаются не громче безопасного уровня. Открыть файлы схемы `audiohw` может только root.

## Linux
`rtkhda-dev` ничего не отправляет железу: он читает текстовый дамп кодека из `/proc/asound` и показывает, что сделал
бы драйвер.

## Как сообщить об уязвимости
Через закрытое сообщение об уязвимости на странице репозитория в GitHub (Security → Report a vulnerability), не в
открытом обсуждении.
