# rtkhda-0257

Звук ноутбука Lenovo ThinkBook 16 G6 ABP (тип 21KK) для Redox OS: контроллер HD Audio AMD (1022:15e3) с кодеком
Realtek ALC257 (10ec:0257). Драйвер — мост: он ведёт контроллер и разговаривает с кодеком, а библиотека
[sonus](https://github.com/Redox-openDriver/sonus) решает, какой выход и микрофон включить, по какому пути до них
дойти и с какой громкостью.

На Linux звуком уже занимаются ядро и PipeWire: здесь есть только инструмент, который по дампу кодека из `/proc`
показывает, что сделал бы драйвер, и ничего не отправляет железу.

## Чем он лучше `ihdad` из Redox
`ihdad` выбирает выход один раз при запуске, у него один путь к ЦАП, нет микрофона и громкости. Этот драйвер:
- переключается на наушники и обратно на динамик, когда их вставляют и вынимают, по сообщениям гнёзд;
- включает наушники не громче безопасного уровня;
- у динамика и наушников своя громкость и свой ЦАП, как в Linux; громкость по слуховой кривой;
- берёт микрофон гарнитуры, пока она вставлена, иначе встроенный цифровой;
- даёт ту же схему `audiohw`, что `ihdad` (корень, `codec`, `audio_shm` для `audiod`), и ещё `volume` и `mute`.

## Что готово
| часть | что делает |
|---|---|
| `core` | контроллер HD Audio без привязки к ОС: сброс, поиск кодеков, кольца команд CORB и RIRB, где сообщения гнёзд отделены от ответов, прерывания, потоки и списки буферов; проверено на поддельном контроллере, который читает команды из кольца, как настоящий |
| `redox` | демон `rtkhdad`: BAR0 и прерывание через `pcid`, DMA, кодек через `sonus`, поток 44,1 кГц 16 бит стерео, схема `audiohw`; `config.toml` для `pcid` берёт контроллер этого ноутбука и ICH9 из QEMU. Собран и проверен компилятором под Redox, ещё не запускался |
| `linux` | `rtkhda-dev show` — кодек, выходы и микрофоны и путь к каждому; `rtkhda-dev verbs [headphones] [headset]` — команды драйвера при запуске и после подключения гнезда |

## Попробовать на Linux
```sh
cargo build --release
target/release/rtkhda-dev show
target/release/rtkhda-dev verbs headphones
```
